# The Whiskey Student — website

Astro static site, deployed to GitHub Pages by `.github/workflows/deploy.yml`.

- `npm run dev:sample` — preview with sample tastings
- `npm run dev` — preview with real data
- Edit `src/site.config.ts` for links and the newsletter form.
- `src/data/tastings.json` and `videos.json` are written by Whiskey Student HQ. Don't edit them by hand unless you aren't using HQ.
- Guides: Markdown in `src/content/guides/`. Set `draft: true` to hide one.
